Что умеет OnlyFam

💬

Личные чаты

Текстовые сообщения, ответы, редактирование, статусы доставки и прочтения. Всё в реальном времени.

⏱

Исчезающие сообщения

Сообщения автоматически удаляются с сервера через выбранный таймер — до 7 дней. История не хранится вечно.

🔒

Шифрование

Текст шифруется на устройстве. На сервере — только зашифрованные данные. Защищённая переписка с mutual-контактами.

📞

Звонки

Аудио- и видеозвонки через LiveKit. Push-уведомления о входящих звонках, даже когда приложение закрыто.

📇

Mutual-контакты

Написать можно только тому, кто есть у вас в телефоне и кто добавил вас в свой список. Никакого открытого поиска.

🏠

Свой сервер

Open-source стек: NestJS, PostgreSQL, Redis, MinIO. Без Firebase. Данные под вашим контролем.

Приватность по умолчанию

  • Вход только по номеру телефона (SMS-код)
  • Доступ к адресной книге — обязательное условие
  • Нет публичных профилей и открытого поиска
  • Push без текста зашифрованных сообщений
  • Самохостинг — вы владеете инфраструктурой
«Мессенджер не для всех — только для тех, кому вы действительно доверяете.»
